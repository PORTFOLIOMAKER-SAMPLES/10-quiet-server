## 화면이 없는 사람은 무엇을 보여 줘야 하나

프론트엔드 신입([09](https://github.com/PORTFOLIOMAKER-SAMPLES/09-first-commit))은 만든 화면을 보여 주면 됩니다.
백엔드·앱 신입은 보여 줄 화면이 없습니다. 그래서 이 견본은 **"어떻게 무너지고 어떻게 살렸는가"** 를 축으로 짰습니다.

- **일부러 낸 장애** — 프로젝트마다 DB를 내려 보고, 워커를 강제 종료하고, 비행기 모드로 열어 봤습니다
- **숫자로 남는 개선** — "검색 4s → 90ms", "이미지 1.2GB → 180MB"
- **일지가 곧 실력 증명** — `Log` 페이지에 주차별로 그 주에 막힌 것을 그대로 적었습니다. 잘 풀린 날보다 안 풀린 날 글이 깁니다
- **틀린 것을 지적해 달라고 먼저 말하기** — 혼자 배운 사람의 가장 큰 약점을 스스로 열어 둡니다
- **저장소 링크** — 다섯 개 카드 전부 GitHub 주소가 붙어 있습니다

## 이 견본이 쓴 설정

| | |
|---|---|
| 템플릿 | 레이어 히어로 (첫 화면부터 시작하는 구성) + 상단 Nav |
| 테마 | 포레스트 |
| 글꼴 | 세리프 |
| 구성 | 3페이지 (Home · Log · Contact) · 한 페이지(퀵메뉴) |
| 3D | `clock.glb` (알람 시계) + 포토스튜디오 HDRI 스카이박스 |
| 효과 | 스크롤 등장 · 틸트 카드 · 패럴랙스 · 인트로 로더 · 부드러운 스크롤 |
| 프로젝트 | 5건 (API · 안드로이드 앱 · 배포 자동화 · 알림 큐 · 문서 자동화) |
| 사진 | 6장 |
| 용량 | 약 4.0 MB |

**Home** — 첫 화면, 손에 익은 순서로 적은 스택 태그, 프로젝트 5건, 3D 알람 시계와 "새벽 두 시에 배운 것".
**Log** — 스크롤 확대 커버, 주차별 개발 일지 6편, 지적 요청 CTA.
**Contact** — 스택이 흐르는 마퀴, 연락처, 링크 목록.

3D 알람 시계는 장식이 아니라 주제입니다. 장애는 대부분 새벽에 납니다.

## 그대로 가져다 쓰기

1. [portfoliomaker.site](https://portfoliomaker.site) 접속
2. 상단 **저장 · 불러오기** 아이콘 클릭
3. **파일에서 불러오기** → 이 저장소의 `quiet-server.pbproj` 선택

카드 상세 칸에는 **막힌 곳 / 일부러 낸 장애 / 다음엔** 세 줄 틀이 들어 있습니다.
본인이 실제로 겪은 것으로 바꿔 넣으면 그대로 쓸 수 있습니다.

## Portfolio Maker 는 어떤 도구인가요

- **설치 없음 · 가입 없음** — 브라우저에서 바로 시작합니다
- **틀 → 내용 → 꾸미기 → 내보내기** 네 단계로 끝납니다
- 테마 18종, 글꼴 10종, 파트 15종 이상을 조합합니다
- 3D 모델(`.glb`) 뷰어, 무료 사진 검색, 다크/라이트 토글이 기본 제공됩니다
- 빌드 도구 없는 정적 파일이라 GitHub Pages에 그대로 올라갑니다 — 이 저장소가 그 증거입니다
